# LAST NODE – 신서울 옥상 방어전

2089년 신서울, 비 내리는 아케론 타워 320m 옥상. 거대 기업 **헬릭스**의 사이보그 군단에게서 도시의 마지막 자유 네트워크 노드 **오로라 코어**를 지키는 1인칭 웨이브 생존 FPS(브라우저 · PC/휴대폰).

- **플레이:** https://vecar0.github.io/Sniper/last-node/
- 기획서: [`design/plan.md`](design/plan.md) · 검수 기록: [`progress.txt`](progress.txt)

## 핵심
- **지켜야 할 목숨이 둘** — 내 체력(100)과 코어 내구도(1500). 둘 중 하나라도 0이면 끝.
- **빠른 액션** — 기본 이동 7m/s, 대시 2회 충전, 더블 점프, 슬라이드. 체력은 저절로 차지 않고 처치하면 나오는 **시안 구슬**로만 회복.
- **적 6종** — 리퍼(칼날 돌격) · 집행관(엄폐 사격) · **리치(코어에 붙어 흡수)** · 스웜 드론(연쇄 자폭) · 메크(정면 방패, 등이 약점) · 보스 무장 수송기 카론(5웨이브마다, 엔진 2개를 부수면 조종석 노출).
- **정비 시간** — 단말에서 무기(산탄총·펄스 라이플·레일건)와 강화를 살지, **코어 실드·자동 포탑·EMP 펄스**에 투자할지 고른다.
- 모든 적 공격은 빛·소리로 **예고**된다(빨간 레이저, 바닥의 빨간 원·선).

## 조작
| 행동 | PC | 휴대폰(가로) |
|---|---|---|
| 이동 · 시점 | WASD · 마우스 | 왼쪽 끌기 · 오른쪽 끌기 |
| 사격 · 정조준 | 좌클릭 · 우클릭 | [발사](누른 채 끌면 조준도) · [조준] |
| 대시 · 점프 · 숙이기/슬라이드 | Shift · Space(공중에서 한 번 더) · C | [대시] · [점프] · [앉기] |
| 근접(기절한 적은 즉시 처치 + 체력 25) | V | [근접] |

| 재장전 · 무기 | R · 1~4 / 휠 / Q | [장전] · [무기] |
| 상점 · 웨이브 바로 시작 · 일시정지 | F · Enter · Esc | [상점 열기] · [준비 완료] · [II] |

## 실행
빌드 도구가 없다. 정적 서버로 폴더를 열면 된다(ES 모듈이라 파일 더블클릭은 브라우저가 막는다).
```bash
cd last-node
python3 -m http.server 8765      # → http://localhost:8765
```

## 테스트
```bash
node --test tests/*.test.js   # 헤드리스 27개: 기획서 완료 기준 + 자동 플레이 봇 밸런스(8시드)·교착 검사 (~1분)
node tests/e2e.mjs            # 실제 브라우저 12개: PC·모바일 터치·재시작 누수·콘솔 에러 0건 (서버를 8765에 띄운 뒤)
```
`?test`를 주소에 붙이면 테스트용 훅(`window.__ln`)이 열린다.

## 구조
| 위치 | 내용 |
|---|---|
| `js/config/` | 모든 수치(`balance.js`, 값마다 이유 주석), 옥상 배치도(`map.js`) |
| `js/sim/` | 렌더와 분리된 시뮬레이션(Three.js 없음): 충돌·광선·격자 길찾기(`geom.js`), 플레이어 이동·무기(`player.js`), 적 AI(`enemies.js`), 웨이브·경제·코어·포탑·상점(`world.js`) |
| `js/render/` | Three.js r170(`vendor/`): 하늘·도시 원경·비·번개·환경맵(`env.js`), 옥상(`level.js`), 적 모델(부품 병합 SkinnedMesh, 적 1기 = 그리기 1번, `models.js`), GPU 파티클·폭발·예고 표시(`fx.js`), 1인칭 총(`viewmodel.js`), 블룸·후처리(`renderer.js`) |
| `js/ui/` · `js/input/` · `js/core/` | HUD·메뉴·상점 / 키보드·마우스·터치 / 저장·합성 사운드 |
| `textures/` · `scripts/textures.py` | Higgsfield로 만든 basecolor → Moisan 주기 분해(이음새 제거) + 노멀·거칠기 생성 |

## 성능 예산(기획서) · 측정값
| 항목 | 예산 | 측정(최악 장면: 적 20 + 보스 + 폭발 3 + 탄흔 60) |
|---|---|---|
| 그리기 호출 | ≤ 250 | 194 |
| 삼각형 | ≤ 50만 | 24만 |
프레임이 떨어지면 해상도를 자동으로 낮춘다(최저 0.6배). 실기기 FPS는 이 개발 환경(소프트웨어 렌더러)에서 측정하지 못했다.
