# NORTHLIGHT – 북천 기지

2071년 북극권 고원. 연락이 끊긴 군 연구 기지 **북천 기지**의 무인 방어 체계가 폭주했다. 회수 작전에 투입된 단독 요원이 되어, 끝없이 몰려오는 군사 로봇을 **빠르게 쓸어 담고, 웨이브마다 강해지며** 살아남는 1인칭 아레나 웨이브 FPS(브라우저 · PC/휴대폰).

- **플레이:** https://vecar0.github.io/Sniper/last-node/
- 기획서: [`design/plan.md`](design/plan.md) · 검수 기록: [`progress.txt`](progress.txt)

## 핵심
- **지킬 것은 없다, 빨리 잡을수록 강해진다** — 2.5초 안에 다음 적을 처치하면 점수 배수가 0.1씩 올라 최대 2배. 웨이브를 기준 시간(30 + 4×웨이브 초) 안에 끝내면 보너스 점수와 체력.
- **보급(상점)** — 처치·기준 시간 보너스로 크레딧이 쌓이고(연속 처치 배수도 적용), 정리 화면에서 체력·방어구·탄약·EMP·무기를 산다. 회복 값은 웨이브마다 오른다.
- **강화 카드(로그라이트)** — 웨이브를 정리할 때마다 카드 3장 중 1장(공짜): 새 무기(산탄총·소총·레일건), 무기 개량 3단계, 능력(최대 체력·방탄판·대시 충전·정밀 사격·EMP 탄띠 …). 보스를 잡으면 희귀 카드(과부하 회로·충격 돌파·사선)가 섞인다.
- **빠른 액션** — 기본 이동 7m/s, 대시 2회 충전, 더블 점프, 슬라이드. 체력은 저절로 차지 않고 처치하면 떨어지는 구슬로 회복.
- **현실형 군사 로봇 6종** — 하운드(4족 로봇개, 돌격·도약) · 보병 로봇(엄폐 후 점사) · **수리 로봇(6륜 차량, 다친 아군을 고침 → 먼저 잡을 표적)** · FPV 자폭 드론(무리, 연쇄 폭발) · 무인 전투차량(앞 장갑판 70% 감소, 뒤 엔진이 약점) · 보스 틸트로터 건십(5웨이브마다, 로터 2개를 부수면 동체 3배 피해).
- 모든 공격은 빛·소리로 **예고**된다(빨간 레이저, 바닥의 빨간 원·선).
- **실제 파지법** — 소총은 C-클램프(왼손이 핸드가드 앞을 받치고 엄지를 앞으로), 권총은 엄지 앞으로(두 엄지가 표적을 가리킴), 산탄총은 왼손이 펌프를 감싸 쥠.
- **사람 관절처럼 움직이는 팔·손** — 몸에 붙은 어깨에서 실제 비율(위팔 29 cm · 아래팔 26 cm)로 고정된 2관절 IK(팔꿈치가 아래·바깥으로 접히고, 손이 멀면 팔이 늘지 않고 어깨가 따라 나감). 위장 무늬 전투복 소매(끝단 벨크로·솔기·주머니·팔꿈치 보호대) + 손목을 덮는 전술 장갑, 손가락 3마디·엄지 2마디 뼈대(쏠 때 검지가 방아쇠를 당기고, 총·탄창을 놓을 때 펴졌다가 잡을 때 다시 쥔다).
- **화려한 근접 공격(V)** — 긴 총은 개머리판 수평 타격 후 공중에 던져 한 바퀴 돌리고 다시 받아 쥐기, 권총은 방아쇠울에 검지를 걸고 한 바퀴 반 돌려 거꾸로 쥔 손잡이 밑으로 찍은 뒤 다시 돌려 쥐기.
- **실제 같은 1인칭 동작** — 왼손이 탄창을 빼고 새 탄창을 끼우는 단계별 재장전(빈 탄창이면 슬라이드·노리쇠 처리), 쏠 때마다 슬라이드·노리쇠 왕복과 탄피 배출, 산탄은 한 발씩 손으로 장전, 8자 걷기 흔들림·관성·숨쉬기.
- **실물 같은 총** — 검은 금속 리시버 + FDE(모래색)·올리브 폴리머 두 톤, 핸드가드 모따기·가공선·나사·점각 손잡이·완충관 링·탄창 와플 결, 뷰모델 자체 그림자(조준경·손이 총에 그림자). 움직이지 않는 부품은 재질별로 합쳐 총 1정 = 그리기 20~50번.
- **실사풍 극지 기지** — 해 진 직후의 청색 하늘과 눈구름·달, 3D 설산 지형, 콘크리트 옹벽 광장, 레이돔 탑, 나트륨 투광등과 눈발에 걸린 빛줄기, 위를 향한 면에만 쌓이는 눈.

## 조작
| 행동 | PC | 휴대폰(가로) |
|---|---|---|
| 이동 · 시점 | WASD · 마우스 | 왼쪽 끌기 · 오른쪽 끌기 |
| 사격 · 정조준 | 좌클릭 · 우클릭 | [발사](누른 채 끌면 조준도) · [조준] |
| 대시 · 점프 · 숙이기/슬라이드 | Shift · Space(공중에서 한 번 더) · C | [대시] · [점프] · [앉기] |
| 근접(기절한 적은 즉시 처치 + 체력 25) | V | [근접] |
| EMP 수류탄 | G(떼면 던짐) | [EMP] |
| 재장전 · 무기 | R · 1~4 / 휠 / Q | [장전] · [무기] |
| 정리 화면: 카드 · 보급 · 작전 재개 | 1~3 · 4~0 · Enter | 탭 |
| 다음 웨이브 바로 시작 · 일시정지 | Enter · Esc | [준비 완료] · [II] |

## 실행
빌드 도구가 없다. 정적 서버로 폴더를 열면 된다(ES 모듈이라 파일 더블클릭은 브라우저가 막는다).
```bash
cd last-node
python3 -m http.server 8765      # → http://localhost:8765
```

## 테스트
```bash
node --test tests/*.test.js   # 헤드리스 28개: 기획서 완료 기준 + 자동 플레이 봇 밸런스(8시드)·교착 검사
node tests/e2e.mjs            # 실제 브라우저 12개: PC·모바일 터치·카드 선택·재시작 누수·콘솔 에러 0건 (서버를 8765에 띄운 뒤)
```
`?test`를 주소에 붙이면 테스트용 훅(`window.__ln`)이 열린다.

## 구조
| 위치 | 내용 |
|---|---|
| `js/config/` | 모든 수치(`balance.js`, 값마다 이유 주석), 강화 카드(`cards.js`), 광장 배치도(`map.js`) |
| `js/sim/` | 렌더와 분리된 시뮬레이션(Three.js 없음): 충돌·광선·격자 길찾기(`geom.js`), 플레이어 이동·무기(`player.js`), 로봇 AI(`enemies.js`), 웨이브·카드·점수(`world.js`) |
| `js/render/` | Three.js r170(`vendor/`): 하늘·3D 설산 지형·눈발·환경맵(`env.js`), 기지 광장(`level.js`), 눈 쌓임 재질(`materials.js`), 로봇 모델(부품 병합 SkinnedMesh, 1기 = 그리기 1번, `models.js`), 파티클·폭발·예고 표시(`fx.js`), 1인칭 총(`guns.js`·`viewmodel.js`), 블룸·후처리(`renderer.js`) |
| `js/ui/` · `js/input/` · `js/core/` | HUD·메뉴·카드 화면 / 키보드·마우스·터치 / 저장·합성 사운드(극지 바람·발전기·전투 음악) |
| `textures/` · `scripts/textures.py` | Higgsfield로 만든 basecolor(거푸집 콘크리트·바닥 콘크리트·눈·도장 강판) → Moisan 주기 분해(이음새 제거) + 노멀·거칠기 생성 |

## 성능 예산(기획서) · 측정값
| 항목 | 예산 | 측정(최악 장면: 로봇 20 + 보스 + 폭발 3 + 탄흔 60) |
|---|---|---|
| 그리기 호출 | ≤ 220 | 188 |
| 삼각형 | ≤ 45만 | 34만 |
프레임이 떨어지면 해상도를 자동으로 낮춘다(최저 0.6배). 실기기 FPS는 이 개발 환경(소프트웨어 렌더러)에서 측정하지 못했다.
