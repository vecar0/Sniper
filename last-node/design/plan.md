# LAST NODE — 기획서 v0.2 (승인 대기)

> 2089년 신서울. 거대 기업 **헬릭스**가 도시의 마지막 자유 네트워크 노드 **"오로라 코어"**를 뺏으려 한다.
> 너는 해커 집단이 고용한 경호원 "러너". 비 내리는 320m 높이 타워 옥상에서 **코어를 지키며** 밀려오는 기업 사이보그 군단을 웨이브마다 막아낸다.
>
> 1인용 · 1인칭 3D 웨이브 거점 방어 FPS · 빠른 액션 · PC 브라우저 + 모바일 가로 · 새 프로젝트(`last-node/`)

## 0. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 장르 | 웨이브 생존 + **거점 방어** 아레나 FPS (참고: DOOM Eternal의 이동·템포, CoD 좀비의 웨이브·상점, 오버워치 화물 방어의 거점 압박) |
| 차별점 | **두 개의 목숨을 지킨다** — 나(체력 100) + 코어(내구도 1500). 적은 각자 나 또는 코어를 노린다. "저 해커를 먼저 잡을까, 내 뒤 칼날놈을 먼저 잡을까"를 매 순간 판단 |
| 템포 | 빠른 액션: 대시 2회 충전 · 더블 점프 · 슬라이드. 서 있으면 죽는다. 탄약은 넉넉(처치 시 드롭) |
| 한 판 | 웨이브 1개 60~100초 + 정비 20초. 10웨이브 ≈ 15~20분, 실력 따라 무한 |
| 패배 | 내 체력 0 **또는** 코어 내구도 0 |
| 표현 수위 | 적은 사이보그·드론. 맞으면 스파크·파란 냉각액·부품. 붉은 피 없음 |
| 아트 | **사실적·어두움**: 젖은 콘크리트와 금속에 비친 네온, 비, 안개, 저 아래로 펼쳐진 도시 불빛, 날아다니는 차량 불빛, 거대한 홀로그램 광고판. 아군 = 시안/파랑, 적 = 헬릭스의 빨강/주황 (색으로 피아 즉시 구분) |

### 핵심 루프
```
웨이브 시작(경보 + 헬릭스 방송) → 3방향에서 적 유입(계단실 · 화물 엘리베이터 · 수송기 강하)
  → 이동(대시·점프)하며 사격 · 코어 공격하는 적 우선 처리
  → 처치마다 크레딧 · 탄약/체력 오브 드롭
  → 웨이브 정리 → 정비 20초: 상점(무기·강화) + **코어 강화**(실드·자동 포탑·EMP 펄스)
  → 다음 웨이브(5웨이브마다 보스: 무장 수송기 "카론")
```

### 맵: 아케론 타워 옥상 (약 56×56m, 지상 320m)
```
              N  [화물 엘리베이터]
   ┌─────────────────────────────────────┐
   │ 냉각탑   ║ 홀로그램 광고판 (뒷면은 철골) │
   │ (2층)    ║                          │
   │   ┌───계단                ┌─────┐    │
 W │   │      [포탑 자리]       │헬리 │    │ E  ← 수송기 강하 지점
[계단실]   ◎ 오로라 코어 ◎      │패드 │    │
   │         (중앙, 지름 4m)    │(2층)│    │
   │  컨테이너  [상점 단말]      └──계단┘    │
   │   환기구 더미     물탱크         난간 틈 │ ← 떨어질 수 있음
   └─────────────────────────────────────┘
              S  (난간, 아래는 도시)
```
- **2단 구조**: 메인 데크(0m) + 냉각탑 플랫폼(4m, 서쪽) + 헬리패드(4m, 동쪽). 각 계단 1개 + 더블 점프로 바로 올라갈 수 있는 상자 계단.
- 중앙 **오로라 코어**: 파랗게 빛나는 원기둥. 주변 낮은 엄폐 링(1m)이 있어 코어 방어 중 숙일 수 있음.
- 적 유입구 3곳: **서쪽 계단실 문**(W1~), **북쪽 화물 엘리베이터**(W2~, 한 번에 4~6기 쏟아짐), **동쪽 헬리패드 수송기 강하**(W4~, 로프 강하 3기).
- 남쪽·동남쪽 난간 틈 2곳: 대시로 잘못 나가면 추락 → 계단실 앞에서 다시 시작, 체력 −30.
- 원경: 수백 개 빌딩(창문 발광), 비행 차량 흐름, 빗줄기, 번개 깜빡임(20~40초마다).

## ② 자원 · 경제 규칙

- 자원 1종: **크레딧(₵)**.
- 획득: 처치(위 표) · 약점 처치 +50% · 근접 처치 +30% · 연속 처치(2.5초 안) 2연속 +10%, 5연속 +25% · 웨이브 정리 보너스 `200 + 50 × 웨이브` · **코어 무피해 웨이브 +300**.
- 소비:
  | 품목 | 가격 |
  |---|---|
  | 무기 3종 | 1000 / 1600 / 3200 |
  | 무기 강화 | 무기 가격 × 0.5 / 0.75 / 1.0 |
  | 방어구 +25 (최대 50) | 400 |
  | 체력 완전 회복 | 250 + 20 × 웨이브 |
  | EMP 수류탄 1개 (최대 3) | 200 |
  | 코어 수리 +300 | 400 |
  | 코어 실드 1/2/3단계 | 800 / 1400 / 2200 |
  | 자동 포탑 1기 / 2기 | 1200 / 1800 |
  | 코어 EMP 펄스 | 2000 |
- 시작: 0₵, EMP 1개. 예상 누적 수입: W2 ≈ 1500, W5 ≈ 4500 → 2~3웨이브에 산탄총 또는 라이플, 5웨이브 보스 전에 포탑 1기 또는 실드 1단계 — **"내 무기 vs 코어 강화" 사이에서 고민**하게 만드는 것이 경제의 목적.

## ③ 적 AI 행동 (구체적 숫자)

### 웨이브 구성
- 총 적 수 `N(w) = 10 + 4w` (상한 80). **동시 생존 상한 20** (보스 웨이브 12 + 보스).
- 체력 배수 `1 + 0.07(w−1)`, 피해 배수 `1 + 0.04(w−1)` (각 상한 ×2.2).
- 유입: 계단실 0.6~1.0초마다 1기 / 엘리베이터 12초마다 4~6기 한꺼번에 / 수송기 18초마다 3기 강하(1.5초 예고: 빛 + 소리).
- 구성 비율(등장 웨이브 이후): 리퍼 40% · 집행관 25% · 리치 12% · 스웜 드론 15%(무리 단위) · 메크 W6부터 웨이브당 `floor(w/3)`기.
- 리치는 같은 시간에 최대 `1 + floor(w/4)`기만 코어에 접속.
- 정비 20초 (Enter / 버튼으로 바로 시작).

### 개체 행동
| 적 | 상태 흐름 | 숫자 |
|---|---|---|
| 리퍼 | 추적(격자 A*, 0.35초마다 경로 갱신) → 3m 안이면 0.3초 웅크림(예고) → 도약 → 칼날 | 같은 무리끼리 1m 분리, 도약 빗나가면 0.6초 경직 |
| 집행관 | 엄폐점 선택(플레이어와 10~26m, 시선 있음, 다른 집행관과 4m 이상) → 이동 → 3점사 → 5~8초마다 재배치. 플레이어 5m 안이면 옆으로 회피 | 명중률 기본 40%, 플레이어가 대시·공중이면 −25%p. 예광탄(탄속 70 m/s) |
| 리치 | 코어 최단 경로로 이동(플레이어 무시) → 코어 2m 앞 접속(케이블 이펙트) → 흡수 | 맞으면 0.4초 접속 끊김(흡수 중단), 레이더·화면 가장자리에 표시 |
| 스웜 드론 | 무리(3~5) 대형으로 비행 고도 2~5m → 대상 4m 안이면 0.5초 깜빡임 후 돌진 | 하나 터지면 1.5m 안 다른 드론도 연쇄 폭발 |
| 메크 | 코어로 느리게 이동, 플레이어 쪽으로 방패 회전 1.0 rad/s → 코어 공격. 25m 안 플레이어에게 미사일 (1초 빨간 레이저 예고) | 뒤로 돌아가면 냉각 코어를 쏠 수 있음 |
| 보스 카론 | 옥상 위 12~18m 높이에서 원 궤도 → 패턴 ①②③ 반복 | 엔진 1개 파괴마다 고도 −4m, 2개 파괴 시 조종석 노출 ×3 |

- **모든 공격에는 예고(빛·소리)가 있다** → 반응하면 피할 수 있다.
- 피격 반응: 맞은 부위 스파크 + 0.1초 경직(메크·보스 제외). 처치 시 래그돌 대신 부품이 흩어지는 분해 이펙트.
- 헬릭스 방송: 웨이브 시작·보스 등장·코어 50%/25% 때 한 줄 자막("자산 회수를 시작합니다.").

- 키 겹침 확인: WASD 이동과 Q/E/F/G/V/C/R 겹치지 않음. 상점 열린 동안 이동·사격 무시.
- 모바일 조준 보조: 십자선 위 적이면 감도 −35%, ADS 시작 시 최대 3° 끌어줌. 리치는 화면 밖이어도 화살표 표시.
- 설정: 감도(PC/모바일 따로), FOV 75~110(기본 95, 빠른 액션), 볼륨(효과/음악/방송), 그래픽 품질(낮음/중간/높음), ADS 홀드/토글, 화면 흔들림 세기.

## ⑥ 완료 기준 체크리스트 ★ (각 줄 = 테스트 하나)

### 핵심 규칙 (headless 시뮬레이션)
- [ ] 시작 시 체력 100, 코어 1500, 크레딧 0, 권총 14/∞, EMP 1, 웨이브 1
- [ ] 웨이브 w의 총 적 수 `10 + 4w`, 동시 생존 20 이하
- [ ] 적은 열린 유입구(계단실/엘리베이터/수송기)에서만 생긴다. 엘리베이터는 W2, 수송기는 W4부터
- [ ] 리퍼가 장애물을 돌아 플레이어에게 도달해 근접 피해를 준다
- [ ] 리치가 플레이어를 무시하고 코어로 가서 접속, 초당 18씩 코어 내구도를 깎는다. 맞으면 0.4초 흡수가 멈춘다
- [ ] 집행관이 엄폐점으로 이동 후 사격하고, 엄폐물 뒤의 플레이어는 맞지 않는다
- [ ] 스웜 드론이 터지면 1.5m 안 다른 드론이 연쇄 폭발한다
- [ ] 메크 정면 방패 ×0.3, 등 코어 ×2.5, EMP 맞으면 4초간 방패가 꺼진다
- [ ] 약점 명중 ×2, 레일건이 일렬 적 3기를 관통한다
- [ ] EMP가 반경 5m 기계 적을 2.5초 기절시키고, 기절한 적을 근접 처치하면 체력 +25
- [ ] 대시는 2회 충전, 다 쓰면 1.4초마다 1회 회복, 대시 중 피해 50%
- [ ] 더블 점프로 4m 플랫폼(상자 계단 경유)에 오를 수 있다
- [ ] 난간 틈으로 떨어지면 계단실 앞에 다시 나타나고 체력 −30
- [ ] 처치 크레딧(약점 +50%, 근접 +30%, 연속 보너스)이 정확히 더해진다
- [ ] 마지막 적 처치 → 정리 보너스(코어 무피해면 +300) → 코어 +150 수리 → 20초 정비 → 다음 웨이브
- [ ] 상점은 정비 중에만 열리고, 크레딧 부족 시 구매 불가, 크레딧은 음수가 되지 않는다
- [ ] 포탑을 사면 포탑 자리에 생기고, 리치·드론을 우선 쏜다
- [ ] 코어 실드가 코어보다 먼저 피해를 받고, 웨이브 시작 시 가득 찬다
- [ ] 탄창이 비면 사격 불가, 재장전 후 탄창이 차고 예비탄이 준다(권총은 무한)
- [ ] 웨이브 5에 보스가 나오고, 엔진 2개 파괴 시 조종석 피해 ×3, 보스 처치 전엔 웨이브가 끝나지 않는다
- [ ] 체력 0 → "러너 사망", 코어 0 → "코어 함락"으로 게임 오버. 최고 점수·웨이브가 저장되고 새로고침 후에도 남는다
- [ ] 저장 데이터가 손상돼도 기본값으로 시작한다
- [ ] 자동 플레이 봇(이동·조준·사격·상점만 사용)이 8시드 모두 웨이브 4 이상 도달(밸런스 하한), 리치를 무시하는 봇은 코어 함락으로 진다(거점 방어가 실제로 의미 있음), 아무것도 안 하면 웨이브 1~2에서 진다

### 브라우저 실행
- [ ] 메인 메뉴(3D 배경) → 시작 → 옥상 맵·도시 원경·비·HUD가 보인다

- [ ] 사격 시 총구 섬광·반동·소리·탄 감소, 적 명중 시 명중 표시·스파크

- [ ] 코어가 공격받으면 코어가 빨갛게 깜빡이고 상단 바가 줄고 방향 표시가 뜬다

- [ ] 콘솔 에러 0건

### 퀄리티 (스크린샷 육안)
- [ ] 컨셉 아트와 같은 색감: 어두운 밤, 시안·마젠타 네온, 빨강 적, 비, 안개, 블룸

## 기술 구성

- 빌드 도구 없음: `last-node/index.html` + ES 모듈. Three.js r170 + 후처리 addon을 `vendor/`에 직접.
- 고정 타임스텝 60Hz 시뮬레이션 + 렌더 보간. **`js/sim/`은 Three.js를 import하지 않음** → `node --test` headless 테스트·봇.
- 폴더: `js/config`(모든 수치) · `js/sim`(월드·충돌·이동·무기·적 AI·웨이브·경제·코어) · `js/render`(씬·도시 원경·비·모델·이펙트·1인칭 총·후처리) · `js/input` · `js/ui` · `js/core`(저장·사운드) · `textures/` · `css/` · `tests/`.
- 모델: 코드로 만든 모델(PBR 금속 + 발광 부품). 외부 3D 파일 없음.
- 사운드: Web Audio 합성 — 무기별 총성, 대시 휙, 사이보그 발소리, 드론 고음, 코어 경보, 빗소리, 신스웨이브 배경 저음.
- 배포: 기존 GitHub Pages 빌드에 폴더를 복사 → `https://vecar0.github.io/Sniper/last-node/`.

## 사용할 스킬 순서
1. **기획서(이 문서)** → 승인
2. 코드: 시뮬레이션 → 렌더 → UI/입력 (`3d-metal-material`, `3d-sky-background`, `3d-retina-resolution` 참고)
3. **텍스처 스킬**: 컨셉 아트 1장 → 씬 색감 맞추기 → seamless 타일 텍스처 생성·적용
4. **검수 스킬**: ⑥을 테스트로 변환 → headless + 브라우저 → 전부 통과할 때까지 반복 → `progress.txt`
