> 2071년, 기후 붕괴 뒤 사람이 떠난 북부 고원. 해발 2,400m 콘크리트 중계 기지 **「북천 중계소」**에
> 위성망과 연결된 마지막 송신기 **「등대」**가 남아 있다. 정체 모를 기계 군체가 그 신호를 끊으려 몰려온다.
> 너는 혼자 남은 기지 경비원. 눈발과 안개 속에서 송신기를 지키며 웨이브를 버틴다.

## 0. 아트 원칙 (이번 개편의 핵심)

1. **색은 두 가지만 의미를 가진다.** 송신기·아군 = 차가운 흰빛 청록(#9FE8F0), 적 = 붉은 센서(#FF3B2E). 그 외 모든 것은 무채색(회색·검정·흰 눈). 광고판·네온 간판·핑크 하늘·청록 바닥 **전부 제거**.
2. **빛의 출처가 보인다.** 하늘(흐린 푸른 해질녘) 1개 + 기지 투광등(중성 흰색) 4개 + 송신기 자체 발광. 이유 없는 발광 띠 금지.
3. **큰 덩어리, 적은 개수.** 브루탈리즘 콘크리트 블록·벽·기둥. 작은 소품 난립 금지 — 엄폐물은 큰 덩어리 10개 이내.
4. **배경은 실루엣.** 광장 벽 위로 보이는 것은 안개 낀 설산 능선 2겹 + 멀리 서 있는 거대 송신 철탑 1개뿐. 창문 불빛 도시 없음.
5. **질감은 조용하게.** 바닥은 마른 콘크리트 + 얇게 쌓인 눈(움푹한 곳·벽 아래에만). 젖은 반사·과한 노멀 금지.
6. **날씨:** 가벼운 눈발(바람에 비스듬히) + 지면 안개. 비 없음, 번개 없음.

참고 감각: 데스 스트랜딩의 회색 풍경, 하프라이프 2 「콤바인」 구조물의 절제, 「아라발」 같은 브루탈리즘 사진.

## 맵: 북천 중계소 방어 구역 (약 56×56m, 광장 바닥 y=0)

```
                    N  [화물 리프트 — 무리 유입 W2~]
     ┌──────────── 콘크리트 옹벽 8~12m ────────────┐
     │ 관제동 지붕(4m)                투광등 ▲        │
     │ ┌─────┐계단            ┌──블록──┐            │
 W   │ │관제동│                         ┌──────┐    │  E
[보급 터널]═  ▣ 엄폐 블록   ◎ 송신기 「등대」◎  │발전기│    │ ← 절벽 위에서 강하 포드 낙하(W4~)
 (꾸준한 유입)│              (지름 4m, 높이 9m)  │플랫폼│    │
     │  블록     [보급 단말]  낮은 방벽 링      └─계단─┘    │
     │      케이블 드럼        블록      투광등 ▲          │
     └──────────────── 남쪽 옹벽 ───────────────────┘
                 (벽 너머: 안개 낀 설산 능선 + 먼 철탑)
```
- 둘레 전부 옹벽(8~12m) → **떨어지는 곳 없음**(추락 규칙 삭제). 벽 위로는 하늘·능선만 보인다.
- 2단 구조 유지: 서쪽 관제동 지붕(4m) + 동쪽 발전기 플랫폼(4m), 각 계단 1개 + 더블 점프용 블록 계단.
- 중앙 송신기: 콘크리트 받침 위 원통형 장치, 위로 가는 안테나 마스트. 발광은 장치 중간 고리 1줄 + 꼭대기 표시등만.
- 유입구: 서쪽 **보급 터널**(꾸준히) / 북쪽 **화물 리프트**(W2~, 4~6기) / 동쪽 **강하 포드**(W4~, 절벽 위에서 3기 낙하, 1.5초 전 붉은 표식).
- 투광등 4기: 모서리 기둥 위, 광장을 비추는 중성 흰빛. 바닥에 큰 빛 웅덩이 → 공간감.

## ⑤ 화면 구성 (UI) — 절제된 HUD

- **흰색 단색 + 반투명**, 패널·테두리·배경 박스 없음. 글자 그림자로만 가독성 확보.
- 색 사용 규칙: 청록 = 송신기 관련만, 빨강 = 위협·피해만, 그 외 전부 흰색/회색.
- 화면 위 요소 수를 줄인다:

| 위치 | 요소 |
|---|---|
| 상단 중앙 | 송신기 바(얇은 1줄) + 웨이브 숫자. 남은 적 수는 숫자만 작게 |
| 중앙 | 작은 점 십자선(이동 시 벌어짐), 명중 표시, 대시 2칸 |
| 왼쪽 아래 | 체력 숫자 + 얇은 바(방어구는 바 위에 겹침) |
| 오른쪽 아래 | 탄창 숫자(크게) / 예비(작게), 무기 이름 1줄 |
| 왼쪽 위 | 레이더: **위협 있을 때만** 나타남(정비 시간엔 숨김) |
| 오른쪽 위 | 크레딧만. 처치 피드 삭제(대신 명중 표시) |
| 가장자리 | 피격 방향 호(빨강), 송신기 공격 방향(청록), 화면 밖 침식체 화살표 |
| 오버레이 | 웨이브 시작/정리: 큰 숫자 1개 + 한 줄, 글리치 효과 삭제. 상점: 목록형 2탭(장비/송신기). 메인 메뉴: 눈 내리는 광장 장면 위 제목 + 메뉴 4줄 |

- 무전 자막(구 헬릭스 방송): 기지 관제 AI의 짧은 한 줄("남쪽 터널, 접근 신호 다수."), 하단 중앙, 3초.
