> 2071년 북극권 고원. 연락이 끊긴 군 연구 기지 **「북천 기지」**의 무인 방어 체계가 폭주했다.
> 기지에 남은 군사 로봇들이 끝없이 몰려온다. 너는 회수 작전에 투입된 단독 요원.
> **지킬 것은 없다. 빠르게 쓸어 담고, 강해지고, 오래 살아남아라.**
>
> 1인용 · 1인칭 3D **아레나 웨이브 + 강화 선택(로그라이트)** FPS · 빠른 액션 · PC 브라우저 + 모바일 가로
> 제목 **NORTHLIGHT** (폴더·URL은 `last-node/` 유지)

## 0. 아트 원칙 — 실사풍

1. **현실에 있는 것만.** 극지 연구 기지: 콘크리트 옹벽, 흰 레이돔(구형 레이더 덮개), 위성 안테나, 철골 통신탑, 컨테이너형 막사, 연료 탱크, 디젤 발전기, 나트륨 투광등. 발광은 실제 조명기구(투광등·경고등·차량 라이트·LED 표시등)뿐.
2. **빛:** 해 진 직후 짙은 청색 하늘 + 실제 오로라(초록 위주, 가끔 보라 끝자락) + 별. 투광등의 따뜻한 호박색이 차가운 눈과 대비 — 영화식 청색/호박색 그레이딩.
3. **질감:** 콘크리트(거푸집 자국)·눈·도장 강판·고무. 위를 향한 면에만 눈이 쌓이고, 벽 아래엔 눈더미, 투광등 아래엔 빛 웅덩이.
4. **날씨:** 바람에 날리는 눈발, 지면에 흐르는 눈보라 안개, 투광등 빛줄기(눈 입자에 빛이 걸림).
5. **배경:** 옹벽 너머 설산 능선 3겹(공기 원근), 먼 철골 통신탑(붉은 항공등), 기지 다른 건물 실루엣.

## 맵: 북천 기지 중앙 광장 (56×56m, 바닥 y=0) — 배치는 지금 맵 골격 재사용

```
                N  [화물 승강장 — 무리 유입 W2~]
   ┌──────────── 콘크리트 옹벽 7m (+ 철망) ───────────┐
   │ 투광등                                     투광등 │
   │ ┌───────┐계단                   ┌────────┐       │
 W │ │관제동  │      블록          ┌─┤발전기   │       │ E
[차량 터널]═ (지붕4m)    ◉ 레이돔 탑 ◉     │플랫폼4m │ ← 수직 이착륙 수송 드론이 로봇 투하(W4~)
 (꾸준한 유입)│          (엄폐·랜드마크)    └──계단──┘       │
   │   블록      낮은 방벽 링        연료 탱크          │
   │ 투광등          블록                       투광등 │
   └──────────────────────────────────────────────┘
```
- 중앙: **레이돔 탑**(콘크리트 받침 + 흰 구형 레이돔, 높이 9m). 지킬 대상이 아니라 시야를 가르는 랜드마크·엄폐물. 주변 낮은 방벽 링 유지.
- 2단 구조 유지(관제동 지붕 / 발전기 플랫폼), 둘레 옹벽으로 추락 없음.
- 유입구: 서쪽 **차량 터널**(꾸준히) / 북쪽 **화물 승강장**(W2~, 4~6기) / 동쪽 **수송 드론 투하**(W4~, 1.5초 전 경고등·소리).
- 폭발물: **연료통 ×6**(쏘면 폭발, 피해 70·반경 4.5m) — 기존 배터리 규칙 그대로.

## ② 강화 선택 (상점 대체)

- **웨이브 정리 → 카드 3장 중 1장 선택**(시간 제한 없음, 고르면 다음 웨이브 5초 카운트다운).
- 5웨이브(보스) 뒤엔 **희귀 카드 1장 포함** 보장.
- 카드 풀(예시, 각 카드에 단계가 있으면 최대 3단계):

| 분류 | 카드 |
|---|---|
| 무기 획득 | 산탄총 / 소총 / 레일건 (아직 없을 때만, W1~W3 사이에 최소 1장 보장) |
| 무기 강화 | 해당 무기 피해 +15% / 탄창 +30% / 재장전 −25% |
| 생존 | 최대 체력 +25 / 방어구 +25(재생 없음) / 처치 회복 +50% |
| 기동 | 대시 충전 +1 / 대시 충전 시간 −25% / 슬라이드 중 피해 −50% |
| 공격 | 약점 피해 +25% / 연속 처치 3회마다 다음 탄창 피해 +20% / EMP +1(최대 +2) |
| 희귀 | 처치 시 주변 3m 전기 폭발 / 대시 통과한 적 기절 1초 / 체력 30% 이하에서 피해 +40% |

## ③ 속도 보상 · 점수

- 처치 점수 = 적 기본 점수 × **연속 처치 배수**(2.5초 안 다음 처치: ×1.1, ×1.2 … 최대 ×2.0).
- 약점 처치 +50%, 근접 처치 +30%.
- **웨이브 기준 시간**(`30 + 4w`초) 안에 정리하면 남은 초 × 20점 + 체력 +15.
- 게임 오버: 체력 0 → 결과(도달 웨이브·점수·처치·명중률·약점률·최고 연속 처치·고른 카드 목록·최고 기록).

## ④ 적 AI — 웨이브

- 총 적 수 `N(w) = 10 + 4w`(상한 80), 동시 20 · 체력 ×`1+0.07(w−1)`, 피해 ×`1+0.04(w−1)`.
- 유입: 터널 0.6~1.0초 / 승강장 12초마다 4~6 / 수송 드론 18초마다 3(W4~).
- 구성: 하운드 40 · 보병 로봇 25 · 수리 로봇 12(W2~) · FPV 드론 15(W3~) · 무인 전투차량 W6~ `floor(w/3)`.
- 수리 로봇: 플레이어에서 14m 이상, 다른 로봇 뒤로 이동 → 가장 체력 비율 낮은 아군에게 회복. 회복할 아군 없으면 플레이어와 거리 유지.
- 무인 전투차량: 플레이어 쪽으로 장갑판을 돌림(1.0 rad/s) → 측면·후방 공격 유도.
- 웨이브 사이 정비 시간 대신 **강화 선택 + 5초**.

## ⑦ 완료 기준 체크리스트 ★

### 핵심 규칙 (headless)
- [ ] 시작: 체력 100, 권총 14/∞, EMP 1, 웨이브 1, 점수 0. 코어·크레딧·상점이 없다
- [ ] 웨이브 w의 총 적 수 `10+4w`, 동시 20 이하, 유입구 개방 시점(W2 승강장, W4 투하)
- [ ] 하운드가 장애물을 돌아 플레이어에게 도달해 근접 피해를 준다
- [ ] 보병 로봇이 엄폐 위치로 이동 후 사격하고, 엄폐물 뒤 플레이어는 맞지 않는다
- [ ] **수리 로봇이 다친 아군을 초당 18 회복하고, 맞으면 0.4초 끊긴다. 최대 체력을 넘지 않는다**
- [ ] FPV 드론 연쇄 폭발(1.5m)
- [ ] 무인 전투차량 정면 ×0.3, 후방 ×2.5, EMP로 장갑 판정 4초 해제, 플레이어를 노린다
- [ ] 약점 ×2, 레일건 3기 관통, EMP 기절 + 근접 처치 회복
- [ ] 대시 2회 충전·1.4초 회복·피해 50%, 더블 점프로 4m 플랫폼, 옹벽 밖으로 못 나감
- [ ] **웨이브 정리 → 카드 3장 제시(중복 없음, 최대 단계 카드 제외) → 선택 효과 적용 → 5초 뒤 다음 웨이브**
- [ ] **무기 카드는 W3 정리 전까지 최소 1번 제시되고, 고르면 해당 무기로 바꿔 쏠 수 있다**
- [ ] **연속 처치 배수가 2.5초 안 처치마다 +0.1(최대 2.0), 끊기면 1.0으로**
- [ ] **기준 시간 안 정리 시 남은 초 × 20점 + 체력 15**
- [ ] 웨이브 5 보스, 나셀 2개 파괴 시 동체 ×3, 보스 처치 전엔 웨이브가 끝나지 않는다
- [ ] 체력 0 → 게임 오버, 최고 점수·웨이브 저장, 저장 손상 시 기본값
- [ ] 봇(이동·조준·사격·카드 무작위 선택)이 8시드 모두 웨이브 4 이상, 아무것도 안 하면 웨이브 1~2에서 사망
