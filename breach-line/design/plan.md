| 항목 | 내용 |
|---|---|

### 핵심 루프
```
브리핑(탑다운 도면: 진입문·대원 배치·장비 지정)
  → 대기(대원이 각 문 앞에 붙음)
  → GO 코드(동시 돌입: 문 열기/파괴 + 섬광탄)
  → 방 정리(용의자 경고 → 항복 or 교전, 인질 확보)
  → 다음 구역(즉석 명령으로 문 쌓기·돌입 반복)
  → 결과 평가(점수·별 3개·교전 규칙 위반 목록)
  → 해금(다음 작전·장비)
```

## ② 자원 · 점수 규칙 (이 장르의 "경제")

전투 중 돈을 버는 구조는 없다. 대신 **작전 전 장비 예산**과 **작전 중 소모품**이 자원이다.

### 장비 예산 (브리핑 단계)
- 분대 전체 **장비 포인트 100**. 대원 4명의 장비를 이 안에서 고른다.
- 비용 예: 섬광탄 10 / 연막탄 8 / 폭약 15 / 확장 탄창 5 / 방탄판 강화(체력 +25) 20
- 기본 무기·권총·수갑·미러건은 0포인트.

### 작전 중 소모품
- 탄약: 주무기 탄창 4개 + 장전된 1개. 권총 탄창 3개.
- 투척물·폭약: 브리핑에서 산 만큼. 대원 소지품은 대원이 명령받아서 사용.
- 회복 없음(작전 중 체력은 줄기만 한다).

### 점수 (100점 만점 → 별)
| 항목 | 점수 |
|---|---|
| 인질 1명 생존 확보 | +10 (전원 생존 보너스 +10) |
| 용의자 체포 | +6 / 사살 +2 |
| 증거물 회수 | +1 |
| 대원 부상 | −5/명 |
| **정당하지 않은 사살**(무장 해제·항복 중·경고 없이 비무장) | −15/건 |
| 민간인·인질 오사 | −25/건 |
| 시간 보너스 | 제한 시간의 50% 안에 끝내면 +5 |

- 별: 60점 ★ / 80점 ★★ / 95점 ★★★
- 다음 작전 해금: ★ 1개 이상.

## ③ 적 AI 행동 (숫자로)

### 상태 흐름
```
대기(배치 위치) → 의심(소리 들음) → 경계(무기 들고 소리 쪽 조준)
                                      ↓
            경고받음 → 항복 판정 ─ 성공 → 손들기(무릎) → 체포 대기
                                └ 실패 → 교전(사격·엄폐 이동) → 도주(체력 30% 이하, 일부)
```

### 감지
- 시야: 정면 ±60°, 거리 18m(밝은 방) / 10m(어두운 곳). 엄폐 뒤 숙인 사람은 안 보임.
- 청각: 걷는 소리 5m, 달리는 소리 10m, 발로 찬 문 15m, 총성·폭약 같은 층 전체.
- 반응 시간: 발견 후 첫 발까지 **0.45초**(권총) / **0.55초**(소총) / **0.35초**(중무장). 섬광 맞으면 +4초.

### 항복 판정 (리더·대원이 "손들어!" 할 때)
- 기본 확률: 권총 55% / 소총 35% / 중무장 8%
- 보정: 섬광 맞음 +35%p, 총구가 2명 이상 겨눔 +15%p, 체력 50% 이하 +20%p, 같은 방 동료 쓰러짐 +10%p
- 경고 1회당 1번 판정, 판정 사이 쿨타임 1.5초. 실패하면 30% 확률로 바로 사격.

### 사격 정확도
- 명중률 = 기본 60% × 거리 보정(5m 1.0 / 15m 0.6) × 이동 중 0.5 × 대상이 엄폐·숙임 0.4
- 같은 방 적들은 동시에 다 쏘지 않는다: **한 대상에 최대 2명**만 동시 사격(공정성).

### 인질 행동
- 인질극 작전(5번)에서 제한 시간 6분. 남은 시간 60초부터 HUD 경고, 0초가 되면 인질 1명 처형 → 패배.
- 인질 근처(3m) 용의자는 경고받으면 50% 확률로 인질 뒤에 숨는다(이때 정확히 머리만 노려야 함).

### 아군 대원 AI
- 따라오기: 리더 뒤 2~3m 일렬, 각 대원이 서로 다른 방향(좌·우·후방)을 경계.
- 돌입: 문 열림 후 **0.4초 간격**으로 순서대로 진입, 각자 방의 모서리 → 중앙 순으로 조준.
- 반응: 적 발견 후 첫 발까지 0.5초, 명중률 70%(용의자보다 약간 좋음).
- 교전 규칙 준수: 대원은 **무기를 들고 겨누는 적에게만** 먼저 쏜다. 나머지는 경고 먼저.
- 항복한 용의자는 명령 없으면 가장 가까운 대원이 4초 안에 자동 체포.

## ④ 조작 체계

### PC (마우스 + 키보드)
| 행동 | 키 |
|---|---|
| 이동 / 달리기 / 숙이기 | W A S D / Shift / C |
| 시점 | 마우스(포인터 락) |
| 사격 / 조준 | 좌클릭 / 우클릭 |
| 기울이기 | Q / E |
| 재장전 / 무기 교체 | R / 1·2·3 (휠) |
| 경고("손들어!") | F (짧게) |
| 상호작용(문 열기·체포·증거 회수) | F (대상 앞에서 길게 0.5초) |
| 투척물 | G |
| **명령 휠 열기** | **마우스 가운데 버튼 또는 V** (누르는 동안 휠, 떼면 선택) |
| 팀 선택 | Tab (전체 → Red → Blue 순환) |
| **GO 코드** | **Space** (대기 중인 팀 전부 동시 실행) |
| 일시정지 | Esc / P |

> ⚠️ 키 겹침 규칙: F는 "짧게=경고, 길게=상호작용"으로 구분. 명령 휠이 열려 있는 동안 WASD 이동은 유지하되 마우스 시점만 멈춘다. Space는 점프 없음(이 게임에 점프 없음) → GO 코드 전용.

### 명령 휠 (바라보는 대상에 따라 내용이 바뀜)
| 바라보는 곳 | 명령 |
|---|---|
| 문 | 쌓기(문 옆 대기) / 열고 정리 / 섬광 후 정리 / 폭파 후 정리 / 미러로 확인 |
| 바닥 | 여기로 이동 / 여기 엄호 |
| 항복한 사람 | 체포 |
| 아무 곳 | 따라와 / 대기 / 경계 방향 지정 |
| 하단 공통 | **"GO 대기" 체크**: 켜면 명령을 바로 실행하지 않고 Space(GO)를 기다림 |

### 모바일 (가로 화면, 터치)
| 행동 | 조작 |
|---|---|
| 이동 | 왼쪽 아래 가상 조이스틱(누른 자리 기준) |
| 시점 | 화면 오른쪽 절반 드래그 |
| 사격 | [발사] 버튼(누르고 드래그하면 시점도 같이 움직임) |
| 조준 / 숙이기 / 기울이기 | [조준] [숙이기] [◀] [▶] |
| 재장전 / 무기 | [장전] / 무기 아이콘 탭 |
| 경고 / 상호작용 | [손들어!] / 대상 근처에서 뜨는 상황 버튼 |
| 명령 | [명령] 버튼 → 큰 휠 팝업(손가락을 밀어서 선택) |
| GO 코드 | 대기 중인 팀이 있으면 화면 위 중앙에 큰 **[GO]** 버튼 등장 |
| 보조 | 조준 보정(적 근처에서 시점 이동 속도 40% 감소) 기본 켜짐. 설정에서 끔 |

- 세로로 돌리면 자동 일시정지 + "가로로 돌려 주세요" 안내.
- 모든 버튼 최소 크기 56×56px, 엄지 영역 안. 버튼 위치는 설정에서 옮길 수 있음(2차 범위).

### 카메라
- 작전: 1인칭, 시야각 기본 75°(설정 60~95°).
- 브리핑: 탑다운 도면(2D 캔버스). 휠/핀치로 줌, 드래그로 이동.

## ⑤ 화면 구성 (UI)

### 브리핑 화면
- 왼쪽: 탑다운 도면 — 문 아이콘을 눌러 팀 배치(Red/Blue 색 핀), 진입 방식 선택
- 오른쪽: 대원 4명 카드 — 주무기·장비 선택, 남은 장비 포인트
- 아래: 작전 목표·제한 시간·알려진 정보(용의자 수 추정, 인질 위치 추정)
- [작전 시작] 버튼

### 작전 HUD
| 위치 | 내용 |
|---|---|
| 왼쪽 위 | 분대 상태: 대원 4명 이름·체력 막대·현재 명령(아이콘) |
| 오른쪽 위 | 미니맵(지나온 방만 밝게, 대원·확인된 적 표시) + 남은 시간 |
| 위 중앙 | 목표 진행: 인질 0/2 · 용의자 0/5 |
| 가운데 | 조준점(이동·사격 시 벌어짐), 상호작용 안내 문구 |
| 오른쪽 아래 | 무기 이름·탄약(장전/예비)·투척물 개수 |
| 화면 가장자리 | 피격 방향 표시(빨간 호) |
| 알림 띠 | "Red 팀 문 앞 대기", "용의자 항복", "정당하지 않은 사살!" |

### 결과 화면
- 승리/실패 큰 글씨 + 별 0~3개
- 점수 내역 표(②의 항목별)
- 교전 규칙 위반 목록(몇 초에 누가 무엇을)
- [다시 하기] [다음 작전] [작전 선택]

### 상태 흐름
```
로딩 → 메인 메뉴 → 작전 선택 → 브리핑 → 작전 ⇄ 일시정지(설정·조작법)
                                         ↓
```

## 기술 기본값

- **단일 `index.html` + ES 모듈, 빌드 도구 없음.** 로컬 정적 서버로 바로 실행.
- Three.js를 `vendor/`에 직접 넣어 상대경로 import (CDN 의존 없음). r167 이후 버전은 `three.module.js`와 `three.core.js`를 **둘 다** 넣는다.
- 게임 루프: 고정 타임스텝 60Hz 시뮬레이션 + 렌더 분리, dt 상한 0.1초.
- **시뮬레이션(규칙·AI·판정) 코드는 렌더·DOM과 완전히 분리** → 브라우저 없이 Node에서 헤드리스 테스트 가능.
- 맵은 문자 배치도(텍스트 격자)로 정의 → 작전 추가가 쉽고 자동 검증(모든 방 도달 가능, 인질 위치 유효)이 쉽다.

```
breach-line/
  index.html
  css/game.css
  vendor/three.module.js, three.core.js
  js/
    config/     balance.js(모든 수치), weapons.js, missions.js(배치도)
    sim/        world.js, actors.js, ai.js, squad.js, combat.js, rules.js(교전 규칙·점수)
    render/     scene.js, models.js, fx.js, viewmodel.js
    input/      keyboard-mouse.js, touch.js, command-wheel.js
    ui/         hud.js, briefing.js, results.js, menu.js
    core/       loop.js, state.js, save.js, audio.js
  tests/        (헤드리스 시뮬 테스트, 브라우저 E2E)
```
