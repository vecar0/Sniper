# BREACH LINE

4인 대테러 분대의 리더가 되어 **계획하고, 동시에 돌입하고, 살려서 데려오는** 1인용 3D 전술 CQB 브라우저 게임.
기획서: [`design/plan.md`](design/plan.md) · 검수 기록: [`progress.txt`](progress.txt)

## 실행
빌드 도구 없음. 정적 서버로 폴더를 열면 된다(ES 모듈이라 `file://` 더블클릭은 브라우저가 막는다).
```bash
cd breach-line
python3 -m http.server 8765      # → http://localhost:8765
```
PC: 화면 클릭 → 마우스 잠금. 모바일: 가로 화면.

## 테스트
```bash
node --test tests/*.test.js   # 헤드리스: 완료 기준 + 봇이 5작전 실제로 클리어 (약 1초)
node tests/e2e.mjs            # 브라우저(Playwright, playwright-core 필요): PC·모바일 28항목
```
`?test`를 주소에 붙이면 테스트용 훅(`window.__breach`)이 열린다.

## 기획서와 다른 점 (1차 구현)
- 작전 5는 2층 대신 **한 층 13구역**으로 만들었다(계단·수직 판정 없음).
- 용의자는 제자리에서 돌아서며 교전한다: **도주(체력 30%)·엄폐 이동·인질 뒤에 숨기**는 아직 없다.
- 방별 밝기에 따른 시야 차이(어두운 곳 10m)는 없다. 시야는 모두 18m.
- 명령 휠에 "경계 방향 지정·엄호"는 없다(따라와·대기·이동·쌓기·돌입 3종·미러·체포).
- 그림자는 PC에서도 발밑 블롭 그림자다(동적 그림자 맵 없음). 창문 오브젝트는 없다.
- 실기기 FPS는 측정하지 못했다(이 개발 환경은 소프트웨어 렌더러만 있음). draw call·삼각형은 예산의 1/5 이하.
