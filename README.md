# LONG SHOT – 장거리 저격 훈련 시뮬레이터

바람·거리·중력·호흡을 직접 읽고 계산해서 200m~1500m 표적을 한 발로 맞히는 3D 브라우저 게임.

## 게임 정보 (제작자 작성)

| 항목 | 내용 |
|---|---|
| 게임 제목 | LONG SHOT |
| 장르 / 한 줄 설명 | 탄도 계산형 3D 저격 퍼즐 액션 – "바람과 거리를 읽고, 한 발로 끝낸다" |
| 플랫폼과 조작 | PC 브라우저(마우스+키보드) 우선 · 모바일 가로 화면 터치 지원 |
| 실행 방법 | `npm install && npm run dev` → 브라우저에서 표시된 주소 열기 (배포본: `npm run build` 후 `dist/index.html`을 정적 서버로) |
| 목표 플레이어 | 슈팅 게임 경험이 있는 15세 이상. 한 판 1~3분, 한 번에 15~30분 |
| 의도한 핵심 재미 | ① 계산이 맞아떨어졌을 때의 쾌감 ② 숨을 참는 긴장감 ③ 빗나간 이유를 알고 다시 쏘는 성장감 |
| 참고한 게임 | Sniper Elite(불릿캠), Hitman Sniper(짧은 미션 구조), Sniper Ghost Warrior(스코프 조작) |
| 현재 상태 | 마무리 단계 (미션 8개 + 사격장 + 일일 챌린지, 총기 3종, 난이도 3단계) |
| 특히 걱정되는 부분 | 사실적인 탄도가 초보에게 어렵지 않은가 / 모바일 조작감 / 저사양 기기 3D 성능 |
| 건드리지 말았으면 하는 부분 | 탄도 물리 모델(`src/ballistics/`) – 리얼리즘이 정체성. 난이도는 "보조 정보량"으로 조절한다 |

### 콘셉트 메모
- 배경은 **가상 저격 훈련 프로그램**. 표적은 훈련용 로봇과 강철판이라 유혈 표현이 없다. 로우폴리 그래픽도 "시뮬레이션"이라는 설정과 맞는다.
- 그래픽과 소리는 **모두 코드로 생성**한다. 외부 에셋이 없어 라이선스 문제가 없고 로딩이 빠르다.

## 핵심 루프

```
관측(거리·바람 읽기) → 보정(터렛/레티클 홀드) → 사격(숨 참기·방아쇠)
  → 결과(불릿캠 / 흙먼지) → 분석(왜 빗나갔는지 mil 단위로) → 보상(별 3개 → 총기·난이도 해금)
```

| 행동 | PC | 터치 |
|---|---|---|

모든 키는 설정에서 바꿀 수 있습니다.

### 상태 흐름
```
로딩 → 메인 메뉴 → (미션 선택) → 브리핑 → 플레이 ⇄ 일시정지
                                          ↓
                                결과 → 다시 하기 / 다음 미션(브리핑) / 미션 선택
일시정지 → 설정·조작법 → 일시정지 / 미션 나가기 → 메인 메뉴
```
자동 일시정지: Esc, 탭 전환, 창 포커스 상실, 포인터 락 해제, 모바일 세로 전환.

## 테스트

```bash
npm test            # 단위 테스트 (탄도 정확도, 저장 손상 복구, 상태 머신, 호흡, 미션 데이터 검증 등)
npm run test:e2e    # Playwright: 방치·연타·일시정지 12회·창 크기·탭 전환·장시간 80발·모바일 터치
npm run check       # 타입 검사 + 단위 + 빌드 + E2E
```

미션 데이터 테스트는 다음을 자동으로 확인합니다.
- 모든 필수 표적을 터렛 범위 안에서 보정할 수 있는지
- 지형이 표적을 가리지 않는지
- 도주 시간이 볼트 조작 2회보다 긴지(피할 수 없는 실패 방지)
- 압도적으로 좋은 총기가 없는지
- 일일 챌린지 365일치가 전부 풀 수 있는지

`?test`를 주소에 붙이면 자동 테스트용 훅(`window.__longshot`)이 열립니다. 일반 실행에는 노출되지 않습니다.
