# LONG SHOT – Ghost Protocol

계약 저격수가 되어 바람·거리·중력·호흡을 직접 읽고, 표적을 식별해 한 발로 끝내는 전술 암살 3D 브라우저 게임.

## 게임 정보 (제작자 작성)

| 항목 | 내용 |
|---|---|
| 게임 제목 | LONG SHOT |
| 장르 / 한 줄 설명 | 전술 저격 암살 – "표적을 식별하고, 바람을 읽고, 한 발로 끝낸다" |
| 플랫폼과 조작 | PC 브라우저(마우스+키보드) 우선 · 모바일 가로 화면 터치 지원 |
| 실행 방법 | `npm install && npm run dev` → 브라우저에서 표시된 주소 열기 (배포본: `npm run build` 후 `dist/index.html`을 정적 서버로) |
| 목표 플레이어 | 슈팅 게임 경험이 있는 15세 이상. 한 판 1~3분, 한 번에 15~30분 |
| 의도한 핵심 재미 | ① 계산이 맞아떨어졌을 때의 쾌감 ② 숨을 참는 긴장감 ③ 들키지 않고 표적만 제거하는 전술적 긴장 ④ 빗나간 이유를 알고 다시 쏘는 성장감 |
| 참고한 게임 | Hitman Sniper(표적 식별·짧은 작전), Sniper Elite(불릿캠·소음), Sniper Ghost Warrior Contracts(계약·장비) |
| 현재 상태 | 마무리 단계 (자격 심사 3 + 실전 작전 5 + 사격장 + 일일 계약, 총기 3종 + 소음기, 난이도 3단계) |
| 특히 걱정되는 부분 | 사실적인 탄도가 초보에게 어렵지 않은가 / 모바일 조작감 / 저사양 기기 3D 성능 |
| 건드리지 말았으면 하는 부분 | 탄도 물리 모델(`src/ballistics/`) – 리얼리즘이 정체성. 난이도는 "보조 정보량"으로 조절한다 |

### 콘셉트 메모
- **고스트 프로토콜**: 계약 저격수 조직. 자격 심사(강철판) 3단계 → 실전 작전 5개(경비병·핵심 표적·민간인).
- **암살 규칙**: 스코프로 1초 관측하거나 레이저로 조사하면 식별 태그가 붙는다. **민간인 사살 = 작전 실패**. 쓰러진 사람은 그 자리에 남고, 근처를 지나는 사람이 발견하면 경보.
- **잠입 → 저격 → 탈출**: 실전 작전 4개(검은 소나무·회색 도로·철의 능선·마지막 계약)는 건물 입구에서 시작한다. 경비를 피하거나 뒤에서 제압하며 창가 저격 위치까지 이동 → 창밖 표적 저격 → EXIT까지 탈출.
  - 경비 시야: 정면 ±55°, 서 있으면 12m / 숙이면 7m. 서서 걸으면 4m 안의 경비가 발소리를 듣는다. 낮은 상자는 숙인 사람을 가린다.
  - 소음기 없이 쏘면 건물 안 경비가 8초 뒤 저격 위치로 수색하러 온다. 소음기만 = 멈춰서 귀 기울임, 소음기+아음속 = 못 들음.
  - 건물은 문자 배치도로 정의(`missions.ts`의 `interior`), 규칙·수치는 `src/game/interior.ts` 맨 위.
- **은밀성**: 총성 전파 범위 = 일반탄 전체 / 일반탄+소음기 400m(반응 느림) / 아음속탄 250m / 아음속탄+소음기 없음.
- **표현 수위**: 유혈 표현 없음. 무력화되면 쓰러진다.
- **아트**: 로우폴리 + 시간대별 조명(새벽·흐림·황혼) + ACES 톤매핑, 전술 단말기 UI. 그래픽·사운드는 **모두 코드로 생성**(외부 에셋 없음).

## 핵심 루프

```
잠입(숙이기·제압·우회) → 관측(표적 식별·거리·바람 읽기) → 보정(▲▼◀▶ 칸 / 조준점 옮기기) → 사격(숨 참기)
  → 결과(불릿캠 / 탄착 표시) → 분석(몇 cm 빗나갔고 ▲를 몇 번) → 탈출 → 보상(별 3개 → 총기·난이도 해금)
```

### 상태 흐름
```
로딩 → 메인 메뉴 → (미션 선택) → 브리핑 → 플레이 ⇄ 일시정지
                                          ↓
                                결과 → 다시 하기 / 다음 미션(브리핑) / 미션 선택
일시정지 → 설정·조작법 → 일시정지 / 미션 나가기 → 메인 메뉴
```
자동 일시정지: Esc, 탭 전환, 창 포커스 상실, 포인터 락 해제, 모바일 세로 전환.

## 테스트

```bash
npm test            # 단위 테스트 (탄도 정확도, 저장 손상 복구, 상태 머신, 호흡, 미션 데이터 검증 등)
npm run test:e2e    # Playwright: 방치·연타·일시정지 12회·창 크기·탭 전환·장시간 80발·모바일 터치
npm run check       # 타입 검사 + 단위 + 빌드 + E2E
```

미션 데이터 테스트는 다음을 자동으로 확인합니다.
- 모든 필수 표적을 터렛 범위 안에서 보정할 수 있는지
- 지형이 표적을 가리지 않는지
- 도주 시간이 볼트 조작 2회보다 긴지(피할 수 없는 실패 방지)
- 압도적으로 좋은 총기가 없는지
- 일일 계약 365일치가 전부 풀 수 있는지
- 민간인과 표적의 외형이 구별되는지, 소음기·아음속탄 규칙으로 M6를 경계 없이 깰 수 있는지

`?test`를 주소에 붙이면 자동 테스트용 훅(`window.__longshot`)이 열립니다. 일반 실행에는 노출되지 않습니다.
