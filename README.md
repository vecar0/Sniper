# LONG SHOT – 옥상 저격전

옥상을 지키며 몰려오는 적을 **저격총 한 방**으로 쓰러뜨리는 3D 아케이드 총게임(브라우저 · PC/휴대폰).

- **플레이:** https://vecar0.github.io/Sniper/ (메인: 옥상 저격전) · `classic.html` = 이전 정밀 저격 작전 모드
- **건물:** 3층 건물 + 옥상. 옥상 계단실 → 3층 → 2층 → 1층 → 정문으로 밖까지 걸어서 오르내린다. 창문이 실제로 뚫려 있어 2·3층 창가에서도 싸울 수 있다(`src/arena/building.ts`).
- **한 판:** 웨이브마다 적이 늘어난다 → 난간 뒤에 숨었다가(숙이기) 스코프를 열어 고개만 내밀고 저격 → 웨이브 정리 보너스 → 체력 0이면 종료, 최고 점수 저장
- **적:** 소총병(엄폐하며 사격) · 돌격병(정문으로 들어와 계단을 타고 플레이어가 있는 층까지 쫓아옴 → 기관단총으로) · 저격수(창문·급수탑, 빨간 레이저와 반짝임으로 예고 후 강한 한 발) · 중장갑(체력 많음, 머리는 한 방)
- **손맛:** 헤드샷 즉사 + 화면 멈춤 · 처치 피드 · 연속 처치 배율 · 웨이브 마지막 처치는 슬로모션 불릿캠
- **조작(PC):** WASD 이동 · 마우스 조준 · 좌클릭 발사 · 우클릭(누르고 있기) 스코프 · C 숙이기 · R 재장전 · Q 무기 교체 · 휠/E 배율 · Esc 일시정지
- **조작(휴대폰):** 화면 왼쪽 아무 곳이나 눌러 끌면 생기는 조이스틱(이동) · 오른쪽 끌어서 조준 · [발사]를 누른 채 끌어도 조준 · [스코프] [숙이기] [장전] [무기] · 조준 보조(십자선이 적 위에서 감도 낮아짐 + 스코프 열 때 살짝 끌어줌)
- **텍스처:** 힉스필드로 만든 타일 텍스처(바닥·콘크리트·벽·컨테이너·도로)를 `python3 -I scripts/textures.py`로 받아 이음새 검사(seam ratio ≤ 1.3, 넘으면 Moisan 주기 분해) 후 `public/textures/`에 넣는다. 파일이 없으면 코드로 만든 잔무늬 텍스처로 대신한다.
- **코드:** `src/arena/`(game · enemy · map · input · ui · textures)

### 콘셉트 메모
- **고스트 프로토콜**: 계약 저격수 조직. 자격 심사(강철판) 3단계 → 실전 작전 5개(경비병·핵심 표적·민간인).
- **암살 규칙**: 스코프로 1초 관측하거나 레이저로 조사하면 식별 태그가 붙는다. **민간인 사살 = 작전 실패**. 쓰러진 사람은 그 자리에 남고, 근처를 지나는 사람이 발견하면 경보.
- **잠입 → 저격 → 탈출**: 실전 작전 4개(검은 소나무·회색 도로·철의 능선·마지막 계약)는 건물 입구에서 시작한다. 경비를 피하거나 뒤에서 제압하며 창가 저격 위치까지 이동 → 창밖 표적 저격 → EXIT까지 탈출.
  - 경비 시야: 정면 ±55°, 서 있으면 12m / 숙이면 7m. 서서 걸으면 4m 안의 경비가 발소리를 듣는다. 낮은 상자는 숙인 사람을 가린다.
  - 소음기 없이 쏘면 건물 안 경비가 8초 뒤 저격 위치로 수색하러 온다. 소음기만 = 멈춰서 귀 기울임, 소음기+아음속 = 못 들음.
  - 건물은 문자 배치도로 정의(`missions.ts`의 `interior`), 규칙·수치는 `src/game/interior.ts` 맨 위.
- **실내 화기 · 파츠**: 건물 안에서는 권총(P9, 항상) + 주무기(V45 기관단총 / C4 카빈)를 쓰고, 저격총은 창가에서만 꺼낸다.
  - 파츠 4칸: 총구(소음기·보정기) · 조준기(가늠쇠·도트·2배) · 탄창(기본·확장) · 하부(레이저·수직 손잡이). 모두 장단점이 함께 있다(`src/config/sidearms.ts`).
  - 발각되면 즉시 실패가 아니라 교전: 그 경비가 무전기를 들기 전(약 1.5초)에 쓰러뜨리면 경보를 막는다. 경보가 울리면 모든 경비가 온다. 체력 0 = 실패.
  - 기울이기(Q/E): 몸을 조금만 내밀면 경비가 덜 알아보고 덜 맞힌다(×0.5).
- **은밀성**: 총성 전파 범위 = 일반탄 전체 / 일반탄+소음기 400m(반응 느림) / 아음속탄 250m / 아음속탄+소음기 없음.
- **표현 수위**: 유혈 표현 없음. 무력화되면 쓰러진다.
- **아트**: 로우폴리 + 시간대별 조명(새벽·흐림·황혼) + ACES 톤매핑, 전술 단말기 UI. 그래픽·사운드는 **모두 코드로 생성**(외부 에셋 없음).

## 핵심 루프

```
잠입(숙이기·제압·우회) → 관측(표적 식별·거리·바람 읽기) → 보정(▲▼◀▶ 칸 / 조준점 옮기기) → 사격(숨 참기)
  → 결과(불릿캠 / 탄착 표시) → 분석(몇 cm 빗나갔고 ▲를 몇 번) → 탈출 → 보상(별 3개 → 총기·난이도 해금)
```

### 상태 흐름
```
로딩 → 메인 메뉴 → (미션 선택) → 브리핑 → 플레이 ⇄ 일시정지
                                          ↓
                                결과 → 다시 하기 / 다음 미션(브리핑) / 미션 선택
일시정지 → 설정·조작법 → 일시정지 / 미션 나가기 → 메인 메뉴
```
자동 일시정지: Esc, 탭 전환, 창 포커스 상실, 포인터 락 해제, 모바일 세로 전환.

## 테스트

```bash
npm test            # 단위 테스트 (탄도 정확도, 저장 손상 복구, 상태 머신, 호흡, 미션 데이터 검증 등)
npm run test:e2e    # Playwright: 방치·연타·일시정지 12회·창 크기·탭 전환·장시간 80발·모바일 터치
npm run check       # 타입 검사 + 단위 + 빌드 + E2E
```

미션 데이터 테스트는 다음을 자동으로 확인합니다.
- 모든 필수 표적을 터렛 범위 안에서 보정할 수 있는지
- 지형이 표적을 가리지 않는지
- 도주 시간이 볼트 조작 2회보다 긴지(피할 수 없는 실패 방지)
- 압도적으로 좋은 총기가 없는지
- 일일 계약 365일치가 전부 풀 수 있는지
- 민간인과 표적의 외형이 구별되는지, 소음기·아음속탄 규칙으로 M6를 경계 없이 깰 수 있는지

`?test`를 주소에 붙이면 자동 테스트용 훅(`window.__longshot`)이 열립니다. 일반 실행에는 노출되지 않습니다.
